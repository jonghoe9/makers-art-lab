## 초음파 센서 HC-SR04

```cpp title="ultrasonic.ino" linenums="1" hl_lines="5"

#define TRIG_PIN 9
#define ECHO_PIN 8

void setup() {
    Serial.begin(115200);
    pinMode(TRIG_PIN, OUTPUT);
    pinMode(ECHO_PIN, INPUT);
}

void loop() {
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);
    long dist = pulseIn(ECHO_PIN, HIGH) / 58;

    Serial.print(dist);
    Serial.println(" cm");

    delay(100);
}
```

* 초음파는 29us 마다 1cm 이동
* 초음파가 왕복 했으므로 29 * 2 해서 58us
* pulseIn으로 체크한 값이 58이면 1cm 거리에 있다는 의미
* HC-SR04 센서의 측정범위 2cm ~ 4m

### pulseIn()
- `pulseIn(pin, valuse);` value가 LOW 상태로 있다가 HIGH 될때 까지의 시간, us 단위
- 대기시간은 10us ~ 3min
- 대기시간 변경 가능, us 단위, 기본값은 1초 (1,000,000 us)
- `pulseIn(pin, valuse, timeout);` 형식
- 반환값 : `unsigned long`

## 실습 문제 2

* 입력으로 거리 센서 사용
* 출력은 Servo 모터 사요하기

* 거리센서의 측정 거리가 50cm 이하일 때 Servo 를 움직이고(위치값 180), 그 외의 경우 Servo 제자리(위치값 0)로 복귀

```cpp title="ultrasonic_servo.ino" linenums="1" hl_lines="5"
#include <Servo.h>                      //====================== SERVO

#define TRIG_PIN 9
#define ECHO_PIN 8
#define LED_PIN 13                   // ===== LED
#define SV1_PIN 10

Servo sv1;                              //====================== SERVO

void setup() {
    Serial.begin(115200);
    pinMode(LED_PIN, OUTPUT);       // ===== LED
    pinMode(TRIG_PIN, OUTPUT);
    pinMode(ECHO_PIN, INPUT);
    sv1.attach(SV1_PIN);                //====================== SERVO
}

void loop() {
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);
    long dist = pulseIn(ECHO_PIN, HIGH) / 58;

    if(dist < 50) {
      digitalWrite(LED_PIN, HIGH);  // ===== LED
      sv1.write(180);                   //====================== SERVO
    } else {
      digitalWrite(LED_PIN, LOW);
      sv1.write(0);                     //====================== SERVO
    }
    Serial.println(dist);
    delay(100);
}
```
