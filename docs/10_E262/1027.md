# 1027_Mad Mapper 연동하기

스탭모터 제어


## 모터 제어 : 스태핑 모터 28BYJ-48 & ULN2003

### 기본 라이브러리 Stepper 사용

```cpp linenums="1"
#include <Stepper.h>

const int stepsPerRevolution = 2048;    // 28BYJ-48 모터의 1바퀴 스텝 수
Stepper myStepper(stepsPerRevolution, 8, 9, 10, 11);
                                        // IN1, IN3, IN2, IN4 순서 연결

void setup() {
  myStepper.setSpeed(15);               // 속도 설정 (15 RPM)
}

void loop() {
  myStepper.step(stepsPerRevolution);   // 시계 방향으로 1바퀴 회전
  delay(1000);
  myStepper.step(-stepsPerRevolution);  // 반시계 방향으로 1바퀴 회전
  delay(1000);
}
```

#### 도전

* 반바퀴 움직이기
* 시리얼로 숫자 2개 입력 받아 움직이기, 첫번째 숫자는 방향(1=시계, 2=반시계), 두번째 숫자는 클릭 수(1-2048)

### AccelStepper 라이브러리 사용

* AccelStepper 라이브러리 설치 후 사용
* 속도와 위치 제어

```cpp linenums="1"
#include <AccelStepper.h>

// 하프 스텝(Half-step) 구동 모드 설정 (4선식), 풀 스탭은 4
#define MotorInterfaceType 8

// 28BYJ-48 하프 스텝 기준 1회전은 4096 스텝입니다. 풀 스탭은 2048
const int stepsPerRevolution = 4096;

AccelStepper stepper(MotorInterfaceType, 8, 10, 9, 11);

void setup() {
  // 최대 속도 설정 (초당 스텝 수)
  stepper.setMaxSpeed(1000.0);
  
  // 가속도 설정 (초당 가속할 스텝 수)
  stepper.setAcceleration(500.0);
  
  // 최초 목표 위치 설정 (4096 스텝 위치 = 시계방향 1회전)
  stepper.moveTo(stepsPerRevolution);
}

void loop() {
  // 목표 위치에 도달했는지 확인
  if (stepper.distanceToGo() == 0) {
    // 현재 위치가 1회전(4096) 지점이라면 시작점(0)으로 목표 변경
    if (stepper.currentPosition() == stepsPerRevolution) {
      stepper.moveTo(0);
    } 
    // 현재 위치가 시작점(0)이라면 다시 1회전 지점으로 목표 변경
    else {
      stepper.moveTo(stepsPerRevolution);
    }
    delay(1000); // 목표가 바뀐 뒤 1초간 대기 (반복되는 코드가 아닐 때는 삭제하기)
  }
  stepper.run();
}

```

#### 도전

* 시리얼로 숫자 3개 입력 받아 움직이기. 1st: 방향 (1=시계, 2=반시계), 2nd:클릭 수, 3rd: 속도
