# 1027_Mad Maddper 연동

## 1. Mad Mapper용 MadLed

* MadMapper에서 아두이노에 보내는 MadLed 형식은 시리얼 포트로 내용을 보낸다.
* 시리얼 포트 속도는 921600bps (아두이노 최고 속도, 문제가 되면 500000 정도가 적당)
* 줄넘김 없이 계속 이어지는 데이터가 전송됨

### 1.1 MadLED 코드

```cpp linenums="1"
#include <FastLED.h>

#define NUM_LEDS      8
#define DATA_PIN      6          // LED 데이터 핀
#define LED_TYPE      WS2812B
#define COLOR_ORDER   GRB        // 실제 LED 색 순서
#define BRIGHTNESS    255
#define BAUDRATE      921600     // MadMapper Device Setup 값과 동일해야 함
#define MAX_CHANNELS  (NUM_LEDS * 3)

#define MAD_LED_HEADER 0xFF
#define MAD_LED_DATA   0xBE

CRGB leds[NUM_LEDS];

enum State : uint8_t { WAIT_HEADER, WAIT_TYPE, READ_LINE, READ_COUNT_L, READ_COUNT_H, READ_DATA };
State state = WAIT_HEADER;

uint8_t  lineNum = 0;
uint16_t channelCount = 0;
uint16_t channelIdx = 0;

void setup() {
  FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);
  FastLED.setBrightness(BRIGHTNESS);
  FastLED.clear(true);

  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(BAUDRATE);         // USB 시리얼 = MadMapper 연결용 (디버그 출력 금지)
}

void processByte(uint8_t b) {
  // 데이터는 0xFF가 될 수 없으므로 0xFF = 새 패킷 시작 (재동기화)
  if (b == MAD_LED_HEADER) {
    state = WAIT_TYPE;
    return;
  }

  switch (state) {
    case WAIT_HEADER:
      break;

    case WAIT_TYPE:
      state = (b == MAD_LED_DATA) ? READ_LINE : WAIT_HEADER;
      break;

    case READ_LINE:
      lineNum = b;
      state = READ_COUNT_L;
      break;

    case READ_COUNT_L:
      channelCount = b;
      state = READ_COUNT_H;
      break;

    case READ_COUNT_H:
      channelCount |= ((uint16_t)b << 8);
      channelIdx = 0;
      state = (channelCount > 0) ? READ_DATA : WAIT_HEADER;
      break;

    case READ_DATA:
      if (lineNum == 0 && channelIdx < MAX_CHANNELS) {
        ((uint8_t*)leds)[channelIdx] = b;   // 받은 바이트를 R,G,B 순서로 저장
      }
      channelIdx++;
      if (channelIdx >= channelCount) {     // 프레임 완료
        state = WAIT_HEADER;
        FastLED.show();
        digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));  // 수신 확인용
      }
      break;
  }
}

void loop() {
  while (Serial.available() > 0) {
    processByte(Serial.read());
  }
}
```

### 1.2 코드 읽기

* WS2812 사용하기 위해 FastLED 라이브러리 사용
* MadMapper의 DMX 채널 데이터는 0~254 값만 사용됨
* 0xFF는 여러 채널 신호가 포함된 프레임의 시작을 알림
* 연속된 신호의 구분은 처음 1개 데이터가 0xFF 로 시작
* 프레임의 2번째는 0xBE (MAD_LED_DATA 식별자)
* 프레임의 3번째는 0x00 (LED 라인 번호, 주로 0 사용, 장비 여러개 연결할 때 식별자)
* 프레임의 4, 5번째는 채널 수 : 총 채널 수 = 4번 데이터 + (5번 데이터 << 8)
* 프레임의 6번 부터 채널 수 만큼의 데이터
* 0xFF 0xBE 0x00 0xXX 0xXX 0xDATA1 .....  0xDATA500 형식으로 구성됨
* 채널 수는 장비당(line) 최대 510개 사용해야 안전

## 2. MadMapper DMX 신호 출력하기

* New Project에서 DMX 체크

### 2.1 출력할 영상 세팅

* Media에서 영상 선택
    * Speed, Scale 변경
* Surface에서 Quad 추가

### 2.2 DMX 세팅

* Fixture에서 Quad 추가
    * Fixture Quad 크기와 위치 조절
    * Fixture Edit 에서 Fixed Size 를 가로 4 x 세로 1 로 수정
    * Pixel Type 을 GRB로 설정 (아두이노 코드와 같이 설정)
    * DMX Universe 0, Channel 1 로 설정 (수정 가능)
* DMX Monitor 창 띄우기 

### 2.3 MadLed 세팅

* Preference / Project / DMX / DMX Out 에서 Artnet 선택
* Artnet 선택 후 나타나는 Interface 에서 Ethernet 127.0.0.1 선택
* Route ArtNet to Arduino for MadLED 체크
* 체크 후 나타나는 LED Routing Device 창에서 + 눌러서 아두이노 포트 추가
* DMX 채널 시작과 끝 설정 (DMX Channel 설정과 같게, 위의 예에서 세팅한 1-12를 세팅)
