# 1027_Mad Maddper 연동

## 1. Mad Mapper용 MadLed

* MadMapper에서 아두이노에 보내는 MadLed 형식은 시리얼 포트로 내용을 보낸다.
* 시리얼 포트 속도는 115200bps
* 줄넘김 없이 계속 이어지는 데이터가 전송됨
* 연속된 신호의 구분은 처음 3개 데이터가 0xFF, 0x00, 0x55 임
* 그 다음은 약속된 갯수 만큼의 DMX 채널을 전송함 (예: DMX CH 1-12)
* "처음 3개 데이터 - DMX 채널 데이터" 이 묶음이 반복됨


### 1.1 MadLED 코드

```cpp linenums="1"
//
// Mad LED, Mad Mapper LED
//
#include <FastLED.h>

// --- 사용자 설정 영역 ---
#define NUM_LEDS    60        // 연결한 총 네오픽셀 LED 개수
#define DATA_PIN    6         // LED 데이터 선을 연결한 아두이노 디지털 핀 번호
#define LED_TYPE    WS2812B   // 사용하는 LED 스트립 종류
#define COLOR_ORDER GRB       // 대부분의 WS2812B는 GRB 순서
#define BAUDRATE    115200    // 매드매퍼 Preferences 설정과 같이 (기본 115200)

CRGB leds[NUM_LEDS];

void setup() {
  Serial.begin(BAUDRATE);
  // FastLED 라이브러리 초기화
  FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);
  FastLED.clear(true);
}

void loop() {
  // 매드매퍼 픽셀 데이터 전송 시작을 알리는 헤더(0xFF, 0x00, 0x55) 확인
  if (Serial.available() >= 3) {
    if (Serial.read() == 0xFF) {
      if (Serial.read() == 0x00) {
        if (Serial.read() == 0x55) {
          // 헤더 확인 후, LED 개수만큼 RGB 데이터를 연속으로 읽기
          for (int i = 0; i < NUM_LEDS; i++) {
            while (Serial.available() < 3); // RGB 3바이트가 들어올 때까지 대기
            leds[i].r = Serial.read();
            leds[i].g = Serial.read();
            leds[i].b = Serial.read();
          }
          // LED에 색상 반영
          FastLED.show();
        }
      }
    }
  }
}
```

### 1.2 코드 읽기

* WS2812 사용하기 위해 FastLED 라이브러리 사용
* 라이브러리 초기화,
* 시리얼 읽기, 데이터에서 3개 바이트가 시작코드인거 확인
* 시작코드 이후 LED 갯수 만큼 데이터 읽기


## 2. MadMapper DMX 신호 출력하기

* New Project에서 DMX 체크

### 2.1 출력할 영상 세팅

* Media에서 영상 선택
    * Speed, Scale 변경
* Surface에서 Quad 추가

### 2.2 DMX 세팅

* Fixture에서 Quad 추가
    * Fixture Quad 크기와 위치 조절
    * Fixture Edit 에서 Fixed Size 를 가로 4 x 세로 1 로 수정
    * Pixel Type 을 GRB로 설정 (아두이노 코드와 같이 설정)
    * DMX Universe 0, Channel 1 로 설정 (수정 가능)
* DMX Monitor 창 띄우기 

### 2.3 MadLed 세팅

* Preference / Project / DMX / DMX Out 에서 Artnet 선택
* Artnet 선택 후 나타나는 Interface 에서 Ethernet 127.0.0.1 선택
* Route ArtNet to Arduino for MadLED 체크
* 체크 후 나타나는 LED Routing Device 창에서 + 눌러서 아두이노 포트 추가
* DMX 채널 시작과 끝 설정 (DMX Channel 설정과 같게, 위의 예에서 세팅한 1-12를 세팅)
